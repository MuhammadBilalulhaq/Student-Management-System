### Student Management System

Dynamic Student Dashboard is a web-based student management project developed using **HTML, CSS, Bootstrap, and JavaScript**. The project displays student information in a clean and responsive dashboard using Bootstrap cards.

Currently, student cards are generated dynamically using **JavaScript DOM manipulation** instead of writing each card directly in HTML. JavaScript is used to create elements, set attributes, add Bootstrap classes, and insert the cards into the dashboard.

Each student card displays basic information such as the student's name, department, semester, and profile image. The project also includes student profile modals where additional information can be viewed.

The project is designed to be **upgraded gradually**. Future improvements can include adding new students dynamically, search and filtering, student registration forms, edit and delete functionality, data validation, local storage or database integration, authentication, and a complete student management system.

**Technologies Used:**

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* DOM Manipulation

**Current Focus:**
JavaScript DOM manipulation and dynamically generating Bootstrap student cards.

**Future Goal:**
Transform the project from a simple student dashboard into a complete and interactive **Student Management System**.
